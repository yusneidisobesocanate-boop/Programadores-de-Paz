BACKLOG PRIORIZADO

1. Como ciudadano quiero registrar una incidencia para dejar evidencia del caso.

2. Como coordinador quiero recibir una alerta en Telegram cuando se registre un nuevo reporte para darle seguimiento oportuno.

3. Como miembro del equipo quiero consultar los reportes registrados para revisar avances y hacer seguimiento.

4. Como coordinador quiero generar un listado de incidencias para organizar las acciones pendientes.

5. Como ciudadano quiero conocer el estado de mi reporte para saber si ya fue atendido.
